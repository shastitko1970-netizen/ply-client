Ply 1.2.0

КАК ЗАПУСТИТЬ
1. Запусти PlySetup.exe (обновит 1.0/1.1, поставит в Program Files).
2. Права администратора — согласись.
3. Ищи Ply в меню Пуск, как Telegram.
4. Вставь ссылку Paper, нажми «Включить VPN».
5. Крестик сворачивает в трей, туннель живой.
   Выход: правый клик по значку у часов → «Выйти и погасить туннель».

Happ и приложение Paper выключи.
SmartScreen: Подробнее → Выполнить в любом случае.
