Ply 1.0.0 — клиент Paper для Windows
====================================

1. Запусти PlySetup.exe
2. Если Windows SmartScreen покажет синее окно:
   «Подробнее» → «Выполнить в любом случае»
   Подписи нет, это самосбор, не вирус.
3. Установщик положит файлы в:
   C:\Users\<ты>\AppData\Local\Ply
   и сделает ярлык на рабочем столе.
4. Вставь ссылку из кабинета Paper.
5. Выключи Happ и приложение Paper. Один VPN.

Ключ с двумя # чистится сам. Mux выключен.
Системный прокси 127.0.0.1:10808. TUN нет.

Репозиторий: https://github.com/shastitko1970-netizen/ply-client
