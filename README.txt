Ply 1.1.0

КАК ЗАПУСТИТЬ
1. Запусти PlySetup.exe. Если уже стоит 1.0 — он обновит сам.
2. Windows спросит права администратора. Согласись.
3. Ply появится в меню Пуск (Все приложения) и на рабочем столе.
4. Открой Ply, вставь ссылку из кабинета Paper, нажми «Включить VPN».
5. Когда написано «VPN включён» — трафик идёт в туннель Ply Tunnel.

Happ и приложение Paper выключи. Один слой.
SmartScreen: Подробнее → Выполнить в любом случае.
