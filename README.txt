Ply 1.4.0

КАК ЗАПУСТИТЬ
1. Запусти PlySetup.exe (обновит 1.0–1.3, поставит в Program Files).
2. Права администратора — согласись.
3. Ищи Ply в меню Пуск, как Telegram.
4. Вставь ссылку Paper, нажми «Включить VPN».
5. «Россия напрямую» включена: .ru, .рф, Яндекс, VK — без VPN.
   Остальное (Grok, Cursor, Google) — через туннель.
6. Крестик сворачивает в трей. Выход — из значка у часов.
7. Новые версии: кнопка «Проверить обновления» в самом Ply.

Happ и приложение Paper выключи.
SmartScreen: Подробнее → Выполнить в любом случае.
