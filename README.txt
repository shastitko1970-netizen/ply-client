Ply 2.1.2

КАК ЗАПУСТИТЬ
1. Запусти PlySetup.exe. Ядро ставится само, Go качать не надо.
2. Окно без прав. UAC — только у ядра, потом значок у часов.
3. Вставь ключ: vless://, hy2://, vmess://, trojan://, ss:// или ссылку подписки.
4. Если в подписке несколько узлов — кнопка «список», выбери один. Он запомнится.
5. «Обновить подписку» тянет свежие узлы. Если сервис сменил ссылку, поле ключа обновится само.
6. Тихий вход: при входе в Windows окно не всплывает, туннель поднимает ядро.
7. Крестик закрывает окно. Ядро остаётся у часов. Включить VPN — правый клик по значку.
8. Список «VPN» в Windows не трогай. Там больше нет пункта Ply.
9. «Не выпускать» — если ядро падает, чужие программы наружу не ходят.
10. «Диагноз» копирует хвост лога, если сайт молчит.
11. Внешний вид: шестерёнка — светлая или тёмная тема.

Другие VPN-клиенты выключи.
SmartScreen: Подробнее → Выполнить в любом случае. Сборка не подписана.
TUIC и WireGuard пока нет — Xray TUIC не умеет, WireGuard сюда не тащим.
macOS kill-switch пока нет: тумблер так и скажет.
