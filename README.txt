Ply 2.0.0

КАК ЗАПУСТИТЬ
1. Запусти PlySetup.exe. Ядро ставится само, Go качать не надо.
2. Окно без прав. UAC — только у ядра, потом значок у часов.
3. Вставь ключ: vless://, hy2://, vmess://, trojan://, ss:// или ссылку подписки.
4. Тихий вход включён: при входе в Windows окно не всплывает, туннель поднимает ядро.
5. Крестик закрывает окно. Ядро остаётся у часов.
6. Внешний вид: шестерёнка — светлая или тёмная тема.

Другие VPN-клиенты выключи.
SmartScreen: Подробнее → Выполнить в любом случае.
TUIC пока нет — Xray его не умеет.
