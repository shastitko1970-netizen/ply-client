# Ply

Windows VPN. Вставила ключ — туннель встал. Не Happ. Не v2rayN.

Понимает **Paper**, любой **vless://**, **hy2://**, **vmess://**, **trojan://**, **ss://** и https-подписку с такими строками (в том числе base64). Mux выключен. Российские сайты идут напрямую, остальное — через узел. Крестик сворачивает в трей.

TUIC Xray не умеет.

## Скачать

Релиз **1.8.0**: [github.com/shastitko1970-netizen/ply-client/releases/tag/v1.8.0](https://github.com/shastitko1970-netizen/ply-client/releases/tag/v1.8.0)

1. Скачай **Ply-1.8.0-win64.zip**, запусти **PlySetup.exe**
2. Ядро Xray ставится само. Go качать не надо. Автозапуск включён.
3. С 1.3+ можно обновить из самого Ply
4. На ПК окно широкое: кнопка слева, карточки справа. Если узко — прокрутка
5. Галочка «Россия напрямую» — .ru / .рф / Яндекс / VK мимо VPN
