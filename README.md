# Ply

Windows VPN. Вставила ключ — туннель встал. Не Happ. Не v2rayN.

Два процесса: **окно** и **ядро**. Окно — тот же HTML, что сайт (Newsreader, карточки блоками). Крестик закрывает окно — **PlyCore** остаётся в трее и держит туннель.

Понимает **Paper**, **vless://**, **hy2://** / **hysteria2://**, **vmess://**, **trojan://**, **ss://** и https-подписку. Mux выключен. Россия мимо, остальное через узел.

TUIC Xray не умеет.

## Скачать

Релиз **1.10.0**: [github.com/shastitko1970-netizen/ply-client/releases/tag/v1.10.0](https://github.com/shastitko1970-netizen/ply-client/releases/tag/v1.10.0)

1. Скачай **Ply-1.10.0-win64.zip**, запусти **PlySetup.exe**
2. Ядро PlyCore ставится само, автозапуск — на ядро, не на окно
3. С 1.3+ можно обновить из самого Ply
4. Крестик = окно спит. Выход из VPN — только из трея
