# Ply

Windows-клиент [Paper VPN](https://papervpn.io). Ссылка из кабинета — ключ чистится сам, Mux выключен, поднимается **VPN-туннель**. Российские сайты идут напрямую, остальное — через Paper. Крестик сворачивает в трей.

Не Happ. Не v2rayN.

## Скачать

Релиз **1.5.0**: [github.com/shastitko1970-netizen/ply-client/releases/tag/v1.5.0](https://github.com/shastitko1970-netizen/ply-client/releases/tag/v1.5.0)

1. Скачай **Ply-1.5.0-win64.zip**, запусти **PlySetup.exe**
2. С 1.3/1.4 можно обновить из самого Ply
3. Большая кнопка питания включает и гасит туннель
4. Галочка «Россия напрямую» — .ru / .рф / Яндекс / VK мимо VPN
