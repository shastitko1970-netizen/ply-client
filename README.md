# Ply

Windows-клиент [Paper VPN](https://papervpn.io). Ссылка из кабинета — ключ чистится сам, Mux выключен, поднимается **VPN-туннель** (Wintun). Крестик сворачивает в трей, туннель не гаснет. Если на GitHub выходит новая версия — Ply сама предлагает обновить.

Не Happ. Не v2rayN.

## Скачать

Релиз **1.3.0**: [github.com/shastitko1970-netizen/ply-client/releases/tag/v1.3.0](https://github.com/shastitko1970-netizen/ply-client/releases/tag/v1.3.0)

1. Скачай **Ply-1.3.0-win64.zip**, запусти **PlySetup.exe**
2. Если стоит 1.0/1.1/1.2 — установщик обновит, ссылку подхватит, поставит в **Program Files**
3. SmartScreen: «Подробнее» → «Выполнить в любом случае»
4. Ищи **Ply** в меню Пуск (как Telegram), не в папке
5. Открой → права администратора → ссылка → **Включить VPN**
6. Крестик = в трей. Выход — правый клик по значку у часов

Когда туннель живой: адаптер **Ply VPN / Ply Tunnel**, дефолтный IPv4 через него (`0.0.0.0/1` + `128.0.0.0/1`), в окне «VPN включён» и IP выхода. Если Windows всё ещё сидит на Wi‑Fi — Ply скажет ошибку, а не притворится.

Дальше обновления ставятся из самого Ply: кнопка «Проверить обновления» / баннер «Вышла v…».
