# Ply

Windows-клиент [Paper VPN](https://papervpn.io). Ссылка из кабинета — ключ чистится сам, Mux выключен, поднимается **VPN-туннель** (Wintun). **Российские сайты идут напрямую**, остальное — через Paper. Крестик сворачивает в трей. Новые версии ставятся из самого Ply.

Не Happ. Не v2rayN.

## Скачать

Релиз **1.4.0**: [github.com/shastitko1970-netizen/ply-client/releases/tag/v1.4.0](https://github.com/shastitko1970-netizen/ply-client/releases/tag/v1.4.0)

1. Скачай **Ply-1.4.0-win64.zip**, запусти **PlySetup.exe**
2. Если стоит 1.3 — можно обновить из самого Ply («Проверить обновления»)
3. SmartScreen: «Подробнее» → «Выполнить в любом случае»
4. Ищи **Ply** в меню Пуск
5. Ссылка Paper → **Включить VPN**. Галочка «Россия напрямую» включена

Split: `.ru` / `.рф` / `.su`, российские IP (`geoip:ru`), Яндекс, VK, Mail.ru, госуслуги — в обход VPN. Google, Grok, Cursor, зарубежные сайты — в туннель. Сними галочку, если нужен полный туннель.

Значок антенны Windows может остаться Wi‑Fi: это радио, не маршрут. Если Ply пишет «VPN включён» и показывает IP — чужой трафик идёт в туннель.
