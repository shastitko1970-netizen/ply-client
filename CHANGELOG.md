# Журнал

## 2.1.7

- Установщик 2.1.6 собрался без значка внутри exe. Окно, трей и ярлык берут иконку из этого ресурса, поэтому везде было пусто. Значок снова вшит в `Ply.exe`, `PlyCore.exe` и `PlySetup.exe`. Сборка останавливается, если ресурса нет.

## 2.1.6

- «Мимо VPN» на Windows больше не приводит имя процесса к нижнему регистру. Xray сравнивает его как есть, поэтому `ZenlessZoneZero.exe`, `Wow.exe`, `Battle.net.exe` снова совпадают. Путь приводится к регистру на диске. Повтор одной и той же строки в разном регистре по-прежнему схлопывается.
- Пресеты «HoYo / ZZZ» и «Blizzard / WoW + Battle.net»: имена процессов, устойчивая папка установки (без номера версии), домены и сети AS57976. Папка ищется в реестре и на всех локальных дисках. После автообновления лаунчера правило не отваливается.
- DNS этих доменов спрашивает провайдера, не узел и не FakeDNS. Запрос ядра не возвращается в туннель: на адрес провайдера ставится отдельный маршрут, а NRPT по-прежнему ведёт остальные имена на `1.1.1.1` внутрь адаптера.
- В «Выбрать» процесс из папки с номером версии предлагает саму папку, а не exe внутри версии.
- «Подробный журнал» пишет, куда ушло соединение и нашлось ли имя процесса.

## 2.1.5

- Значок снова у окна, не у невидимого ядра. Крестик прячет окно, выход — из значка. Пока окно закрыто, ядро молчит и не рисует второй значок. Если окно убито, значок возвращается к ядру.
- Окно тащится за шапку. Раньше команда уходила внутри клика и курсор его не вёл.
- «Выбрать» у списка «мимо VPN»: запущенные программы, установленные exe и папки. Папка с `/` в конце — все процессы внутри. HoYoPlay одной строкой, а не десяток имён.
- Ключ `socks5://логин:пароль@хост:порт` и переключатель «туннель / прокси». Туннель по-прежнему весь трафик. Прокси — системный, без прав и без wintun: браузер, не игры. На Windows это параметры интернета, на macOS `networksetup`, на Linux GNOME `gsettings`. На Android socks5 — вход туннеля, системного прокси нет.
- Пустой список «мимо» не меняет разбор имени. «Не выпускать» в режиме прокси не включается: иначе программы не достучатся до ядра.

## 2.1.4

- Список «мимо VPN» в 2.1.3 стоял после перехвата DNS. Игре выдавался фейковый адрес, и она всё равно шла через узел.
- Теперь её DNS и пакеты уходят напрямую. Браузер не трогаем: пустой список по-прежнему берёт имя из запроса.
- Если у такой программы имя достали из запроса, живой адрес спрашиваем через узел, не у провайдера.
- На Android пакет по-прежнему исключает сам VPN. В конфиг ядра он больше не попадает и не подменяет DNS остальным.
- «Не выпускать» режет и этот список. Иначе это дырка.

## 2.1.3

- Игры и выбранные программы идут мимо VPN. На компьютере — имя как в диспетчере задач. На Android — список установленных приложений, их трафик не входит в туннель.
- Пустой список ничего не меняет: сайты по-прежнему по имени из запроса.
- APK в том же релизе, его можно ставить и проверять: ключ, узлы, РФ напрямую, обход приложений.

## 2.1.2

- Окно снова резкое на масштабе Windows 150% (144 DPI). Сборки 2.1.0 и 2.1.1 рисовались растянутой картинкой, клики промахивались, туннель из такого окна не включался.
- Низ окна листается. Ключ, узлы и ошибка подключения видны, а не обрезаны.

## 2.1.1

- Кнопка «Обновить подписку». Старая ссылка сама сменяется, если сервис прислал новый адрес: заголовок или строка `#new-url` / `#subscription-url`, смена домена `new-domain`, запасной `fallback-url`. Так же, как у Happ.
- Если туннель уже включён, после обновления он поднимается заново на свежем списке.

## 2.1.0

- Подписка — список узлов, не первая попавшаяся строка. Выбор запоминается.
- Kill-switch «Не выпускать»: Windows (политика брандмауэра, наружу только xray) и Linux (iptables). macOS — честный отказ, без притворства.
- Диагноз: хвост лога xray и копирование.
- `url.txt` и каталог узлов: `0600`, на Windows ключ ещё DPAPI. `config.json` стирается при остановке.
- Android больше не включает «VPN», если ключ не разобрался. Раньше в этот момент трафик шёл напрямую.
- Одно окно — HTML. Без WebView2 открывается тот же интерфейс в браузере.
- CI выпускает Windows, Linux и macOS из тега `v*`. Номер версии больше не зашит как 2.0.7. Пуш в `main` релиз не штампует.
- User-Agent снова совпадает с версией клиента.
