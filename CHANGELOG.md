# Журнал

## 2.1.3

- Игры и выбранные программы идут мимо VPN. На компьютере — имя как в диспетчере задач. На Android — список установленных приложений, их трафик не входит в туннель.
- Пустой список ничего не меняет: сайты по-прежнему по имени из запроса.
- APK в том же релизе, его можно ставить и проверять: ключ, узлы, РФ напрямую, обход приложений.

## 2.1.2

- Окно снова резкое на масштабе Windows 150% (144 DPI). Сборки 2.1.0 и 2.1.1 рисовались растянутой картинкой, клики промахивались, туннель из такого окна не включался.
- Низ окна листается. Ключ, узлы и ошибка подключения видны, а не обрезаны.

## 2.1.1

- Кнопка «Обновить подписку». Старая ссылка сама сменяется, если сервис прислал новый адрес: заголовок или строка `#new-url` / `#subscription-url`, смена домена `new-domain`, запасной `fallback-url`. Так же, как у Happ.
- Если туннель уже включён, после обновления он поднимается заново на свежем списке.

## 2.1.0

- Подписка — список узлов, не первая попавшаяся строка. Выбор запоминается.
- Kill-switch «Не выпускать»: Windows (политика брандмауэра, наружу только xray) и Linux (iptables). macOS — честный отказ, без притворства.
- Диагноз: хвост лога xray и копирование.
- `url.txt` и каталог узлов: `0600`, на Windows ключ ещё DPAPI. `config.json` стирается при остановке.
- Android больше не включает «VPN», если ключ не разобрался. Раньше в этот момент трафик шёл напрямую.
- Одно окно — HTML. Без WebView2 открывается тот же интерфейс в браузере.
- CI выпускает Windows, Linux и macOS из тега `v*`. Номер версии больше не зашит как 2.0.7. Пуш в `main` релиз не штампует.
- User-Agent снова совпадает с версией клиента.
